# Задача
Реализовать новый UI/UX карточки принтера согласно требованиям ниже.

Нужно подготовить:
- обновлённый HTML-шаблон карточки;
- необходимый CSS-код;
- JS-функцию для динамического обновления DOM на основе данных от backend.

# Требования к UI/UX
## 1. Индикация температур
- Под элементом `class="status-dot"` разместить текущие температуры стола и экструдера.
- Добавить минималистичные SVG-иконки, соответствующие стилю приложения, отдельно для стола и экструдера.
- Если экструдеров 2 или больше, выводить их температуры через разделитель `/`.
  - Пример: `220°C / 215°C`.

## 2. Статус-бар прогресса печати
- Добавить статус-бар в самом низу карточки, на всю ширину, с небольшим отступом по краям.
- Статус-бар должен быть скрыт по умолчанию и отображаться только если принтер находится в состоянии печати (`"printing"`).

## 3. Поведение при наведении в состоянии печати
- При наведении на карточку печатающего принтера справа от его названия должен плавно появляться процент завершения печати.
- При наведении на карточку должно отображаться текущее название файла.
- Если печать не идёт, поле названия файла и статус-бар должны быть скрыты.

## 4. Динамическая подсветка карточки в состоянии без курсора
- Подсветка карточки, включая border и лёгкое свечение / `box-shadow`, должна работать только когда на карточке нет курсора: `:not(:hover)`.
- При наведении карточка должна возвращаться к дефолтному системному цвету.
- Состояния подсветки:
  - Принтер готов (`"ready"`) — зелёная подсветка.
  - Принтер печатает (`"printing"`) — оранжевая подсветка.
  - Ошибка (`"error"`) — красная подсветка.

## 5. Анимации событий при изменении состояния
- Завершение печати, переход из `"printing"` в `"ready"`:
  - вся карточка должна мигнуть зелёным цветом ровно 3 раза.
- Возникновение ошибки, переход в `"error"`:
  - вся карточка должна мигнуть красным цветом ровно 3 раза.

# Требования к JS-логике
- Написать функцию `updatePrinterCard(cardId, data)`.
- Функция должна принимать:
  - ID карточки;
  - объект с данными от Node.js, включающий:
    - статус;
    - температуру стола;
    - температуры экструдеров в виде массива;
    - прогресс;
    - имя файла.
- Реализовать трекер предыдущего состояния (`state tracker`) для конкретной карточки, чтобы JS мог:
  - отследить момент окончания печати;
  - отследить момент появления ошибки;
  - навесить соответствующий CSS-класс для анимации мигания.
