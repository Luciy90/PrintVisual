# PrintVisual

## Описание проекта

PrintVisual — это продвинутая веб-система мониторинга IP-камер для 3D-принтеров с расширенной системой кастомизации интерфейса, уведомлений и гибкой сеткой отображения. Проект представляет собой полнофункциональное одностраничное приложение (SPA), работающее локально в браузере без необходимости серверной инфраструктуры.

Система обеспечивает централизованный мониторинг множественных 3D-принтеров через их веб-камеры, предоставляя пользователю интуитивно понятный интерфейс для наблюдения за процессом печати в режиме реального времени.

## Основные функции и особенности

### 🎨 Система кастомизации интерфейса
- **Цветовая схема**: Полная настройка палитры интерфейса с живым предпросмотром изменений
- **Адаптивная ширина**: Динамическое изменение ширины рабочей области (800-1920px)
- **Настройка загрузки**: Управление анимацией загрузки, цветом фона и прозрачностью
- **Кастомизация заголовка**: Персонализация текста, цвета и фона шапки интерфейса
- **Гибкие уведомления**: Настройка цветов для системных сообщений и ошибок

### 📹 Управление камерами
- **Автоматическое определение потоков**: Умная система подбора настроек видеопотока
- **Drag & Drop организация**: Интуитивное перемещение камер методом перетаскивания
- **Множественные источники**: Поддержка различных типов IP-камер и потоков
- **Статусные индикаторы**: Визуальное отображение состояния подключения (онлайн/офлайн/предупреждение)
- **Пустые слоты**: Возможность создания резервных мест для будущих камер
- **Полноэкранный режим**: Увеличение видеопотока на весь экран для детального наблюдения

### 🔧 Конфигурация сетки
- **Динамические колонки**: Настройка количества колонок от 1 до 6
- **Визуальные разделители**: Настраиваемые горизонтальные разделители между рядами
- **Точная настройка отображения**: Контроль толщины, ширины, цвета и выравнивания элементов
- **Адаптивный размер текста**: Регулировка размера подписей камер

### 🔄 Система уведомлений
- **Умное сворачивание**: Автоматическое управление стеком уведомлений
- **Анимированные переходы**: Плавные эффекты появления и исчезновения
- **Группировка действий**: Массовые операции с уведомлениями
- **Настраиваемая прозрачность**: Контроль видимости уведомлений

### 💾 Управление конфигурацией
- **Локальное хранение**: Автоматическое сохранение настроек в браузере
- **Импорт/Экспорт**: Полная синхронизация конфигураций между устройствами
- **Сброс к заводским**: Быстрое восстановление настроек по умолчанию
- **Горячие клавиши**: Поддержка клавиатурных сокращений для быстрого доступа

### ⚡ Оптимизация производительности
- **Селективное отключение потоков**: Экономия трафика при открытии веб-интерфейсов принтеров

- **Плавные анимации**: 60 FPS анимации с использованием CSS transforms
- **Responsive дизайн**: Корректное отображение на различных размерах экранов

## Инструкция по запуску и использованию

### Системные требования
- Современный веб-браузер с поддержкой ES6+ (Chrome 70+, Firefox 65+, Safari 12+)
- Сетевой доступ к IP-камерам 3D-принтеров
- Разрешение экрана не менее 800px по ширине

### Быстрый старт через Node.js / Express

1. **Установите зависимости**
   ```bash
   npm install
   ```

2. **Запустите приложение в режиме разработки**
   ```bash
   npm run dev
   ```

3. **Откройте интерфейс**
   ```text
   http://localhost:8765
   ```

4. **Проверьте API**
   ```text
   http://localhost:8765/api/health
   ```

Для production-сборки:

```bash
npm run build
npm start
```

По умолчанию Express отдаёт frontend из папки `public/` и предоставляет REST API для серверных операций. Старый монолитный файл `print 1.8.28.html` сохранён в корне как legacy-источник и fallback, но для получения MAC и сетевого сканирования рекомендуется запуск через Node.js.

Текущая frontend-структура:

```text
public/
  index.html
  styles.css
  api-client.js
  app.js
  redirect.js

src/client/
  api.ts
  app.ts                 # строгая модульная поверхность миграции
  app.legacy-runtime.ts  # проверенный runtime до достижения паритета
  cameras.ts
  notifications.ts
  recovery.ts
  settings.ts
  ui.ts
```

`public/app.js` и `public/api-client.js` являются результатом сборки. Пока модульный клиент не достиг функционального паритета, `public/app.js` собирается из `src/client/app.legacy-runtime.ts`; `src/client/app.ts` и остальные модули проходят отдельную строгую проверку типов. После изменений запускайте:

```bash
npm run build:client
```

### REST API

- `GET /api/health` - проверка состояния сервера.
- `GET /api/settings` - получить сохранённые настройки.
- `PUT /api/settings` - полностью сохранить настройки приложения.
- `PATCH /api/settings` - частично обновить настройки.
- `GET /api/printers/mac?address=192.168.88.115` - получить MAC принтера по адресу.
- `POST /api/printers/mac` - получить MAC с параметрами в JSON body.
- `POST /api/network/scan` - просканировать список подсетей.
- `POST /api/network/recovery-plan` - построить план восстановления IP по сохранённым MAC.

Валидация входных данных выполняется через Zod. Настройки сервера сохраняются в `data/printerCamsV2.json`.

При запуске через Express серверное хранилище является основным источником настроек. Клиент сначала загружает `/api/settings`; если серверное хранилище пустое, но в браузере уже есть старые настройки `localStorage`, они автоматически импортируются на сервер. `localStorage` остаётся совместимым локальным кэшем для старого режима запуска.

### Быстрый старт как один HTML-файл

1. **Запуск приложения**
   ```
   Откройте файл `print 1.8.28.html` в веб-браузере
   ```

2. **Первоначальная настройка**
   - При первом запуске появится модальное окно с условиями использования
   - Ознакомьтесь с правилами и подтвердите согласие
   - Система автоматически перейдет к основному интерфейсу

3. **Добавление камер**
   - Нажмите кнопку "Настройки" (⚙️) в правом верхнем углу
   - Перейдите в раздел "Сетка камер"
   - Используйте кнопки "Добавить камеру" или "Добавить пустой слот"
   - Заполните поля IP-адреса и пути к видеопотоку

4. **Настройка видеопотоков**
   - **IP-адрес**: вводите без `http://` (например: `192.168.0.2` или `192.168.0.2:81`)
   - **Видеопоток**: укажите путь (например: `:8080/?action=stream`)
   - Используйте кнопку автоподбора (🔀) для автоматического определения настроек

5. **Сохранение конфигурации**
   - После настройки нажмите кнопку "Применить" в нижней части панели настроек
   - Для сохранения расположения камер используйте кнопку "Сохранить" (💾) в панели инструментов

## Дополнительная информация

### Техническая архитектура
Приложение переносится на гибридную архитектуру Node.js + текущий HTML-клиент:
- **Backend**: Node.js, Express, TypeScript
- **Валидация**: Zod-схемы для REST API
- **API**: `/api/settings`, `/api/printers/mac`, `/api/network/scan`, `/api/network/recovery-plan`
- **Хранение на сервере**: JSON-файл `data/printerCamsV2.json`
- **Frontend-клиент**: `public/index.html`, `public/styles.css`, `public/api-client.js`, `public/app.js`, `public/redirect.js`
- **Frontend-исходники**: проверенный runtime `src/client/app.legacy-runtime.ts` и строгие модули миграции в `src/client/*.ts`

Клиентская часть по-прежнему использует:
- **Frontend**: HTML5, CSS3 с использованием Tailwind CSS
- **JavaScript**: Vanilla ES6+ без внешних зависимостей
- **Иконки**: Lucide Icons и Font Awesome
- **Хранение данных**: серверный JSON-файл как основной источник при запуске через Express; `localStorage` используется для обратной совместимости и первичного импорта старых настроек
